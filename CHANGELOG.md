# Changelog

This file records user-visible releases of Econ Theorist AI v2. The project
uses semantic versioning for the released open-source core; scientific claims
remain governed by the evidence boundaries in the repository.

## [1.0.0] - 2026-08-01

The first numbered public release of the bounded Econ Theorist AI v2
open-source core.

### Research workflow

- A persistent, dependency-aware research process from question and benchmark
  through mechanisms, formalization, proof challenge, argument validation, and
  manuscript development.
- Researcher-owned gates for consequential scientific choices, with explicit
  revise, pivot, park, and kill outcomes.
- Literature-evidence, closest-theory, absorption-risk, counterexample, and
  economic-interpretation objects that keep distinct claims distinct.

### AI collaboration

- A prepared Codex skill and public machine-protocol path.
- A bounded Codex framing team with one mentor, two independent collaborators,
  and one selected research worker.
- An optional bounded theorem challenge with separate proof and
  counterexample/economics roles.
- Thin Claude Code and Cursor adapters to the host-neutral single-route core.

### Manuscript development

- Structured argument and reader-path foundations, one coordinating writer,
  specialist formal/economic/cold-reader review, and targeted revision.
- Function-first exposition craft that learns what strong papers accomplish
  without copying their prose or authorial signatures.

### Current evidence boundaries

- Pure and applied economic theory only; no empirical or econometric workflow.
- Treat current adapters as public-only until private execution is positively
  validated.
- Codex is the only host with recorded public route execution in this release;
  native Claude Code and Cursor runs remain to be validated.
- Multi-agent research-quality gains, lower researcher effort, stable complete
  working-paper quality, and Top-5 outcomes are not established or guaranteed.
